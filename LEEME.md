# Mariachi Santamaria · landing v2

Sitio estático (HTML + CSS + JS), listo para Vercel sin build.

- `index.html`: la página.
- `assets/css/styles.css`, `assets/js/main.js`: estilos e interacciones.
- `assets/vendor/`: GSAP 3.13 + ScrollTrigger y Lenis, servidos desde el propio sitio.
- `assets/img`, `assets/vid`: fotos y clips optimizados.

Desplegar: subir esta carpeta a un repo de GitHub e importarlo en Vercel
(Framework preset: "Other", sin comando de build, output = raíz), o `npx vercel` desde esta carpeta.

Testimonios: textos provisionales, reemplazar por reseñas reales cuando el cliente las tenga.
